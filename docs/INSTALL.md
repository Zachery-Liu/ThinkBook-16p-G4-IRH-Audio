# 试用与回退

这是开发适配，不是远程一键修复。先确认硬件、provider ABI、正常OEM资源和本机校准，完成主机测试及构建。

1. 先完整备份你实际启动的EFI，并读取核对目标分区UUID。不要套用别人的disk编号，也不要覆盖Windows EFI。
2. 保留原有可启动方案、触控板provider和恢复介质。仅在匹配硬件上更新这两个音频kext；不要把整个陌生EFI覆盖到本机。
3. ALC287使用layout21。沿用现有HDEF注入方式；内部变换成7正常。高音跟随依赖AppleALC的IOHDAFamily executeVerb钩子，**需要 `alcverbs=1` 或对应 `alc-verbs` 属性**。`-cirrusdbg`用于可选诊断；不要照抄参考机的整串boot-args，更不要顺便改安全设置。
4. 核对Lilu依赖顺序、OpenCore实际加载项和读回哈希。内核驱动更换后正常重启，不热加载／卸载Lilu插件。
5. 先用低音量熟悉音乐确认底部，再确认上下两组与左右声道。状态ACTIVE和寄存器读回不能代替物理出声。
6. 另行验证停止播放、耳机插拔、睡眠唤醒及长时间使用。异常时停止播放并回退本次文件；这些项目在参考机尚未逐项完成。

本仓库不安装LaunchDaemon，不使用20ms常驻Pin镜像，也没有自动部署或重启脚本。之前的常驻写Pin方案曾伴随登录故障，不能恢复它充当本实现。

恢复时先比较后续无关配置变化，优先只恢复这两个音频kext对应文件；完整EFI恢复只用于明确需要的情况。Windows、备份盘和其他启动项保持各自独立。
