# 测试与结果

## 本仓库公开回归

`python3 tools/test.py`运行明确列出的12个无OEM资源套件，包括：播放钥匙时序及取消／传输故障，信号遥测的预算／超时／null，寄存器与总线ABI，供电隔离，严格UID校准的合成夹具，调音解析，HDA格式与运行时，以及真实高音状态机、异步调度和合成固件导入测试。

高音与新增时序／遥测测试使用ASan/UBSan。它们不访问真实音频硬件，不读取本机NVRAM，也不携带个人校准。

`src/CirrusAudioFixup/Tests`还保留继承的历史测试。部分需要原上游多机型固件目录，不能在这个只导入17AA38A9的公开配置上冒充通过；入口已转向公开套件。原开发环境曾运行42套维护回归，Windows PowerShell执行项跳过；这不等于公开干净checkout执行了42套。
